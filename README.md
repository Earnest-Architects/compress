# Squish — Earnest Architects

[Squoosh](https://github.com/GoogleChromeLabs/squoosh) にインスパイアされた画像圧縮ツールを、Earnest Architects のブランディングで作り直したものです。

## 機能
- ブラウザ上で画像を圧縮（JPEG、PNG、WebP）— Canvas API を使用し、サーバーへのアップロードは不要
- 元の画像と圧縮後のプレビュー比較、ファイルサイズと削減率の表示
- 形式と品質のコントロール、目標サイズを指定した圧縮
- フォトエディター（Photopea を日本語表示で埋め込み）
- 多言語対応：日本語（デフォルト）、English、Indonesia
- くすんだダークブルー + ブラックのテーマ

## 使い方
`index.html` をブラウザで開くか、静的サイト（GitHub Pages、Netlify、Vercel など）としてデプロイしてください。

依存関係やビルド手順はなく、純粋な HTML/CSS/JS です。

## アプリ（PWA）として Windows にインストール
1. Edge/Chrome でサイトを開きます。
2. アドレスバーの「インストール」アイコンをクリックします（またはメニュー ⋮ →「アプリ」→「このサイトをアプリとしてインストール」）。
3. インストール後、アプリを開き、タスクバーのアイコンを右クリック →「**タスクバーにピン留めする**」。
