# Squish — Earnest Architects

Image compressor terinspirasi dari [Squoosh](https://github.com/GoogleChromeLabs/squoosh), dibuat ulang dengan branding Earnest Architects.

## Fitur
- Kompres gambar langsung di browser (JPEG, PNG, WebP) via Canvas API — tanpa upload ke server
- Preview perbandingan asli vs hasil kompresi + ukuran file & persentase penghematan
- Kontrol format & kualitas
- Multi-bahasa: Indonesia, English, 日本語
- Tema biru pudar gelap + hitam

## Cara pakai
Cukup buka `index.html` di browser, atau deploy sebagai static site (GitHub Pages, Netlify, Vercel, dll).

Tidak ada dependency atau build step — murni HTML/CSS/JS satu file.
